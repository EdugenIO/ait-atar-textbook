Learn to check a workshop request

This demonstration checks invented values on this page. It does not send, save or register a booking. Do not enter personal information.

1. Read the goal

Choose a listed workshop and enter a whole-number group size from 1 to 12. Use the feedback to correct an invalid value.

2. Study the model

Design workshop + 4 people: a workshop is selected and 4 is a whole number within the allowed range. The values should pass these practice rules.

3. Predict, try and explain

  1. Choose Design workshop and enter 13. Predict the result before checking.
  2. Change the value to 12. Explain why the result changes.
  3. Choose Media workshop and try 2.5. Correct it using the rule.
Compare your reasoning after trying

13 is above the maximum. 12 is accepted because the upper boundary is included. 2.5 is inside the numeric range but is not a whole number, so it is rejected.

Try the practice form

Both fields are required. Check the values, read any feedback and correct the relevant field.

Choose one of the two fictional workshops.

Enter a whole number from 1 to 12. Use fictional values only.

What did this check establish?

Accepted values meet this demonstration’s listed-option and whole-number range rules. They do not prove the information is true, reserve places or test a real service’s storage and security.

A real receiving service needs its own validation and appropriate information handling. This page has no receiving service or response storage.
