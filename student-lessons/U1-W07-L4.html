2. Understand the lesson ideas

A useful file must suit its job. Choose formats for the audience and the tools they use, then organise your project data so it can be checked and reused.

Choose an image representation

A raster photograph stores a grid of pixels. Enlarging it beyond its useful resolution can reveal blocky edges. A vector logo describes shapes, so its paths can scale without the same pixel-grid problem. A vector file can still contain a raster image. Check what is actually inside the file, not just its extension.

Explore this concept and its visual/example support

Compare graphic formats

SVG and CGM can represent vector graphics; SVG is widely used for web graphics, while CGM is found in technical graphics workflows. Check support in the chosen application. BMP stores bitmap images and is often large. JPEG commonly uses lossy compression and suits photographs, but repeated lossy exports can reduce quality. PNG uses lossless compression and supports transparency. GIF uses a limited colour palette and can contain animation; it is often unsuitable for full-colour photographs. TIFF supports several storage options and is used in imaging and print workflows. The extension alone does not guarantee resolution, quality or print suitability.

Explore this concept and its visual/example support

Choose an audio format

MP3 uses lossy compression, which can make a small listening copy. WAV is a container commonly used for uncompressed PCM audio, but not every WAV file uses the same encoding. WMA refers to Windows Media Audio formats with different encoding options; check player and editor support. Keep an editable source or a suitable high-quality master. Export a delivery copy, then listen to it on the intended device. Renaming a file extension does not convert its contents.

Deeper chapter model: Retrieve the quantity without guessing
  1. Reference data: A2:C4 has P01 / Poster / 12, A02 / Audio / 8 and V03 / Video / 30. The quantities are fictional classroom data.
  2. Request: E2 contains A02. Find the quantity for that exact code.
  3. Formula: =VLOOKUP(E2,$A$2:$C$4,3,FALSE)
  4. Trace: Find A02 in column A. Stay on its row. Read column 3 of the lookup range: 8.
  5. Test: P01 returns 12; V03 returns 30; X99 returns #N/A because it is absent.
  6. Check: If the table is sorted, move complete rows together. Retest the lookups.

The formula finds a record by its code. It does not mean “always return the second row”.

Spot and correct a connected misconception

Claim to examine: Changing .jpg to .png converts the image.

Compare the correction

The filename changes, but the data does not. Use an export or conversion tool, then check the output.

Supported chapter question

A student uses =VLOOKUP("A02",$A$2:$C$4,2,FALSE) with the worked table. Predict the result and explain why it is not 8.

Check the supported reasoning

It returns Audio, the value in column 2 of the matched row. To return the quantity, use column 3. The FALSE argument controls matching; it does not select the output column.

Related practice and explanation

Explain

Why should an unknown resource code not automatically receive quantity zero?

Compare an explained answer

Zero is a real quantity. It can conceal a missing or incorrect code. Flag the missing record for checking rather than inventing data.
