# Response-handling lab

Start with index.html. Original fictional classroom resources; no grades or student accounts.

Run node server.mjs in this folder. The server binds only to 127.0.0.1:4182. Learner and reviewer URLs are printed locally. All fictional responses and the random reviewer key are memory-only. Stop with Ctrl+C. This is a teaching service, not production authentication or a public deployment.

Record: tool/version, task, expected outcome, actual observation, change, retest and untested cases. Retain teacher/classroom verification separately from resource availability. Original material follows the textbook repository terms.
