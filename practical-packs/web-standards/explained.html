Explain the implementation

Open the finished example, then inspect its source in your editor. The implementation and style sheet are editable.

Structure carries meaning

The single h1 names the event. The h2 elements identify session details and the group task. Main identifies the primary content; the skip link targets its id. CSS controls appearance without replacing heading meaning. The target has tabindex="-1" so it can receive focus without becoming another ordinary Tab stop.

Labels, rules and feedback work together

<label for="people"> points to id="people". Placeholder text is not the only label. The input has type="number" min="1" max="20" step="1" required. Native validation runs before a valid submit event. The capture-phase invalid handler marks the field and explains the rule. Input clears stale error state; submit prevents navigation and displays a local preview.

The feedback region uses role="status". Test its announcement with an actual assistive technology before claiming support in that environment. No request, storage or analytics is implemented. JavaScript-disabled use retains event information and rules but cannot preview.

Internationalisation is more than translation

lang="en-AU" describes the document language; lang="fr" describes the French phrase. <time datetime="2027-05-04">4 May 2027</time> supplies a machine-readable date and a less ambiguous visible date. The example explicitly names Perth as its date context; it does not convert a session time between zones.

Presentation still needs testing

Flexible widths and wrapping help at narrower sizes. A visible focus outline helps a keyboard user locate the active control. Neither feature proves complete accessibility. Test tasks, inspect labels and structure, and record unsupported environments honestly.

Independent transfer

Create a new fictional event with a required whole-number range from 2 to 12. Change both constraints and explanatory text. Test 1, 2, 12, 13 and 2.5; explain which should pass before trying them. Keep labels, messages and expected results consistent with the new rule.
