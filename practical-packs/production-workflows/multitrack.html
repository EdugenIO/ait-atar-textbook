Shotcut or equivalent editor pathway

  1. Create and save a 1280 × 720, 30 fps project. Import the three source cards onto the video timeline, each lasting four seconds.
  2. Add the planned title text using your editor's text filter or title layer. Check all three title intervals and contrast; preserve editable text in the project.
  3. Add separate voice and supporting-tone audio tracks starting at zero. Keep them editable. Reduce the tone and listen with the voice; the reference's linear gains are an example, not a universal loudness target.
  4. Apply the final two-second tone fade and purposeful card fades. If using a dissolve instead, overlaps can alter duration; recheck all timing.
  5. Save the editor-native project, then export from Timeline to a supported MP4 using H.264 video and AAC audio. Reopen the delivered file rather than playing only the editor preview.
  6. Check 1280 × 720, intended 12-second duration, all titles, intelligible voice, no clipping and expected fade. Retain the transcript and event text alternative.
