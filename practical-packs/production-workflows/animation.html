Build and verify a two-second animation

Unit 2 applications · Use your approved animation tool or the editable browser animation starter.

Timing specification · Actual 24-frame reference GIF · Operation record

Worked construction

  1. Create a 640 × 180 canvas and a 24-frame sequence. Keep the horizontal guide still; move the marker from the left to the right over the sequence.
  2. For a frame-by-frame version, explicitly set the marker positions. For a tween, define start/end positions and have the tool calculate intermediate ones. Compare the midpoint and end state.
  3. Set nominal playback to 12 fps: 24/12 = 2 seconds. Save the editable source with its frame/timing information.
  4. Export, reopen and verify the frame count and loop duration. Inspect start, middle and end; do not infer success from an export-complete message.

The actual reference GIF has 24 frames and a 2000 ms cycle. GIF timing uses hundredths of a second: this file repeats 80, 80 and 90 ms holds eight times. Its average duration is two seconds, but each frame is not held for exactly 1/12 second. A video export at fixed 12 fps has a different timing representation.
