Worked operation using ordinary file tools

  1. Create a new folder for this exercise. Copy both supplied CSVs into it; retain the downloads unchanged.
  2. Open each copy in a text editor. Version 1 says Hall 2, capacity 12. Version 2 says Hall 3, capacity 16. Record which version is approved and which change would be lost by an older restore.
  3. Extract the supplied backup ZIP into a separate new restore folder. Inspect the file inside: it is approved-v1.csv, not the working version 2.
  4. Compare the restored contents with the approved original. If available, calculate a SHA-256 digest of both files to compare bytes; the observed reference record supplies the expected digests.
  5. Keep the restored copy and version 2 separate. Decide whether to retain, reconcile or seek approval for the later change; do not overwrite the only newer copy.

A real disposable-file test created a ZIP, replaced its temporary working file and restored version 1. Its restored digest matches version 1 and differs from version 2. The test establishes restoration of those bytes, not that version 1 is the latest, that sync is backup, or that a production recovery plan works.
