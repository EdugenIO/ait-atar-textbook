Read licence terms and plan a software change

Unit 1 · supplementary worked evidence. Read the chapter explanation first.

Worked decisions

Fictional repair café brief: residents must find what to bring, the date, venue and next action. The decisions below model reasoning; they are not observed learner results.

FocusDecision and explanation
Open and closed sourceOpen-source terms grant defined source-use/modification/redistribution rights; being able to view some source is not sufficient. Closed source does not provide the same rights.
ProprietaryAn owner-controlled licence can restrict copying/use; it is not a synonym for paid software.
SharewareA trial allows specified evaluation, perhaps with time/features limited; check what happens after that period.
FreewareNo purchase price does not imply source access or unrestricted redistribution. These labels can overlap.
InstallationFor a fictional editor requiring an unsupported OS, pause. Check exact version requirements, official source, school approval and recoverable work before installation.
UpdateA new version may change file support or plugins. Preserve an editable copy, test representative imports/exports and record the version and outcome.

Apply independently

Compare four invented licence notices: source modification/redistribution allowed subject to terms; no-price binary with copying restrictions; 14-day trial; paid classroom licence. Classify overlapping labels and list two questions to confirm. Write an installation/update go/no-go checklist for a fictional unsupported OS and plugin dependency; no installation is required.

Use this as part of the existing chapter task, not an additional assessed project or extra lesson. Predict outcomes, create/inspect the required output and record the actual result.

Evidence to retain

  • Base each classification on rights, price and conditions separately.
  • Explain both installation and updating, including compatibility and recovery.
  • A plan demonstrates this knowledge requirement; it is not a claim an installer was run.
