Worked decisions

Fictional repair café brief: residents must find what to bring, the date, venue and next action. The decisions below model reasoning; they are not observed learner results.

FocusDecision and explanation
CGMA legacy technical-vector handover requires verified application support. If unsupported, flag it; changing an SVG extension is not conversion.
SVGUse editable paths for a scalable mark; check embedded raster content and target rendering.
BMPA bitmap interchange may be accepted by a legacy tool but is large in this reference set.
GIFUse a palette-based graphic/short animation where appropriate; palette conversion can reduce colour information.
JPEGA compressed photographic delivery copy can trade detail for size; repeated lossy saving can degrade it.
TIFFAn imaging workflow can use a suitable TIFF encoding; the extension does not establish resolution or print readiness.
PNGA lossless screen graphic can preserve sharp edges/transparency; it is not automatically smaller than every alternative.
MP3A lossy listening copy requires a listening/player test and retained source.
WAVThe supplied PCM master supports editing; WAV is a container and not every WAV uses PCM.
WMAA client’s supported player may accept WMA; test support instead of assuming a browser will play it.
OrganisationKeep source/working/exports separate; name versions consistently and retain provenance. A folder scheme does not replace backup.

Apply independently

Use the measured production workflow to export and inspect a raster and audio delivery copy. Modify the vector mark in an approved editor and check its exported appearance. For each named format, write a suitable/unsuitable client condition, including what to do if CGM support is unknown. Submit a folder plan and actual source/export files.

Use this as part of the existing chapter task, not an additional assessed project or extra lesson. Predict outcomes, create/inspect the required output and record the actual result.

Evidence to retain

  • Cover all ten named formats in the decision table.
  • Demonstrate vector, raster and audio use in actual software; do not claim every format was converted.
  • Record size, relevant settings, rendering/playback and a revision.
