# AIT media practical starter pack · v1

A shared fictional Repair cafe brief for Units 1–3. Original diagram-like illustration, vector mark, scene cards, generated practice tone and synthetic narration. No real client records, accounts, purchases or online submissions are needed.

## Start here
1. Extract the ZIP before opening files. Keep the `source`, `templates` and `guides` folder structure.
2. Make a separate working folder and preserve the supplied sources.
3. Open `index.html` for the pack contents and previews.
4. Follow the guide for the chapter you are studying. Use approved applications already available to your class; tool examples do not require installing software.
5. Keep editable projects separately from exports and record actual results in the test log.

## Supplied / learner-produced
Supplied: PNG/SVG masters, three still scene cards, raw/reference narration, tone/reference mix, transcript, CSV templates, editable HTML/SVG publication templates, completed HTML example and three practical guides.
Learner-produced: spreadsheet workbook with formulas, image comparisons, editor-native audio/timeline projects, final video/publication exports and actual test evidence. The pack does not supply or claim verified Audacity/Shotcut project files.

## Rights and provenance
The illustration, SVG mark, cards, tone and publication templates were created for this textbook.
