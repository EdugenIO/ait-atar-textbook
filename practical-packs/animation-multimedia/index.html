Animation task

  1. Play the supplied static starter. It has 24 identical positions, so the wheel stays still.
  2. Change the 24 x positions to make a deliberate frame-by-frame journey. Predict 24 frames ÷ 12 fps = 2 seconds.
  3. Compare the reference positions and switch to tween mode. The same overall path can have different intermediate motion.
  4. Inspect the contact sheet and the 24 editable SVG frames in the ZIP. Import supported frames into an approved animation tool, set the rate and verify duration/output support.
  5. Export and test your actual delivery animation. The browser starter is a working reference, not a claim that a particular editor’s project file has been verified.

Multi-track task

  1. Open the timeline starter. It has three four-second picture scenes, a separate title layer, narration and a supporting tone.
  2. Replace the placeholder titles. Toggle title visibility, set the supporting-track gain and inspect the combined result.
  3. Download your editable plan. Reload its JSON through the plan field and verify that your choices return.
  4. Compare the reference plan. Create the equivalent tracks in an approved editor, then export and inspect a 12-second delivery copy.
  5. Use the earlier editor walkthrough on the website. The ZIP includes its own workflow notes below, so it does not require that link offline.

Offline editor workflow and expected checks

Create a 1280 × 720, 30 fps project if supported. Arrange scene-01, scene-02 and scene-03 for four seconds each on the base track. Use a separate title layer and separate narration/tone audio tracks. Keep the source folder beside the project or relink it deliberately.

At 30 fps, 12 seconds is 360 frames. Preview speech and title readability, preserve an editable native project, export the timeline, then inspect the actual output. Overlapping clips for transitions can change duration: retest instead of assuming it remains 12 seconds.

The transcript is supplied with the files. Check relevant captions and essential visual information for any final video; this starter does not supply a caption file guaranteed to match every learner edit.

Record tool/version, input settings, expected result, actual result, revision and retest. Real editor-native projects and delivery exports are learner outputs; the supplied browser plans are not represented as Audacity or Shotcut project files.
