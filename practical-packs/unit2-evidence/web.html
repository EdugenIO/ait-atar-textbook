Worked decisions

FocusDecision and explanation
Links and navigation mapHome links to Services and Contact; each page provides a labelled return route. A map shows destinations and routes, not just three page names.
GraphicsUse an appropriate supported format with a useful text alternative; check the actual delivered path and dimensions.
TemplatesA repeated header, navigation and footer form a shared layout pattern. Edit consistent elements across pages without forcing identical content.
HTML/HTM and CSSHTML marks up structure and links; .html/.htm are alternative extensions. CSS controls presentation, including layout and spacing. The filename alone does not validate either.
Online collaborationA shared document supports co-editing/comments; asynchronous review leaves a record; a call can resolve questions quickly. Assign editor/reviewer roles and retain approval/version decisions.
Responsive designThe reference stacks cards at a narrow breakpoint rather than shrinking all text. Test narrow/wide, text enlargement, link routes and keyboard focus in the delivered files.

Apply independently

Copy the three-page reference into your working folder. Draw its navigation map, change fictional hours and a long service title, add your edited media/graphic with text alternatives and explain the HTML/CSS roles. Use an approved shared review process, record who changes/approves content, and test every route, narrow/wide layout and keyboard operation.

Use this within the existing chapter task, not an extra assessed project or additional teaching week. Record expected and actual results separately.

Evidence to retain
