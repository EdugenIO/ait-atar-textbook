Manage cloud copies, versions and real utility evidence

Unit 2 · fictional bicycle-shop client brief. Read the chapter explanation first. These are worked decisions, not observed learner results.

Worked decisions

FocusDecision and explanation
Online managementUse a shared approved location, meaningful names, role-based access and an identified approved copy. Check links and permitted access rather than relying on a filename called final.
Version controlA staff member proposes v2; another checks the content and approves it. Retain v1 and a change log. Conflict resolution and rollback need an owner, not merely two renamed copies.
Cloud computingA provider delivers computing/storage services over a network. Collaboration can help remote staff; outages, permissions and sync conflicts still need planning. Sync is not automatically independent backup.
Cleanup/cacheInspect the actual report, identify the specifically approved disposable category and preserve downloads/source files. Clearing cache can remove useful offline copies; a virtual lab is not actual OS operation.
FragmentationTraditional HDD defragmentation addresses scattered storage locations and mechanical access. Use the OS’s drive-aware guidance for SSDs; do not force HDD treatment onto every drive.
Protection categoriesMalware is an umbrella; a virus spreads by infecting host material, spyware monitors/collects covertly, and spam is unwanted messaging that may carry malicious content. Anti-malware/anti-virus and spam filtering have different roles and limits.

Apply independently

Create a v1 document, make a separately saved v2 edit, record the change and approval decision, then restore a disposable copy from an independent backup and compare contents. Complete the linked supervised OS-utility pathway in an approved training environment; if unavailable, mark that skill unverified instead of treating the model as performance.

Use this within the existing chapter task, not an extra assessed project or additional teaching week. Record expected and actual results separately.

Evidence to retain

  • Keep versions, approval history and actual restore evidence.
  • For OS operation record version, drive type, utility, preview/approval, observed action and limits.
  • Do not run unapproved cleanup, disable protection or use malware samples.
