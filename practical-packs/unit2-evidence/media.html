Unit 2 · fictional bicycle-shop client brief. Read the chapter explanation first. These are worked decisions, not observed learner results.

Worked decisions

FocusDecision and explanation
Frame-by-frameExplicitly set each frame; the supplied 24-frame model has a two-second cycle. Check stored timing, not only an fps label.
TweenSet start/end states and inspect calculated intermediate positions. Tweening reduces manual drawing but still requires motion/timing decisions.
ButtonsA Replay control must restart the intended sequence and be reachable by keyboard. A drawn button with no action is not a working control.
Audio editingKeep the source; trim an unwanted portion, adjust level or arrange tracks, then listen to the result. Editing is not a filename change.
Converting/exportingEncode an appropriate delivery format and reopen it on the target player. Retain the editable project separately; exporting a mix can merge editable tracks.

Apply independently

Use approved animation software or the linked editable starter to create a three-second animation and test replay. Edit a supplied audio clip, save the project, convert/export a delivery copy and inspect playback with a transcript. Integrate the actual media into your shop prototype and record a revision.

Use this within the existing chapter task, not an extra assessed project or additional teaching week. Record expected and actual results separately.

Evidence to retain

  • Retain editable animation/audio source and delivered files.
  • Record actual button behaviour, timing, player/tool version and intelligibility check.
  • Distinguish creating/editing from analysing the supplied reference.

Actual learner performance, native application output and independent teacher review remain unverified. Supplied model results must not be copied into an observed-result log.
