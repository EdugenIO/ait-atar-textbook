Optimise a file without losing its purpose

Unit 2 · fictional bicycle-shop client brief. Read the chapter explanation first. These are worked decisions, not observed learner results.

Worked decisions

FocusDecision and explanation
Compression purposeReduce storage/transfer cost while preserving the information required for use. File bytes, visual detail and playback/rendering support are different checks.
Lossy/losslessA JPEG copy may discard image information; a lossless archive must restore original bytes. Lossless compression does not guarantee a smaller file in every case.
CroppingRemoving the opening-hours region reduces content; a smaller image fails the brief if the required hours disappear.
ResamplingThe supplied 1600 × 1000 image is resampled to 800 × 500: pixel count changes from 1,600,000 to 400,000. That quarter pixel count is not a promise of quarter file bytes.
Online/displayThe measured JPEG is 28,592 bytes at 800 × 500. Reopen it and judge text/edges at intended display size.
PrintA 1600-pixel width placed at 8 inches gives 200 PPI; at 4 inches it gives 400 PPI. Confirm the actual output brief, profile and proof requirements rather than using screen pixels as a print specification.

Measured format outputs and independent export brief · Print/profile conditions

Apply independently

Using the supplied master and approved software, produce two delivery copies for a stated screen and print brief. Compare cropping, resampling and compression separately. Reopen each output, measure bytes/dimensions and inspect required information; revise a failing copy.

Use this within the existing chapter task, not an extra assessed project or additional teaching week. Record expected and actual results separately.

Evidence to retain

  • Retain the original and editable work.
  • Label actual settings, measurements, rendering judgement and output conditions.
  • Explain why byte size alone cannot establish a usable result.
