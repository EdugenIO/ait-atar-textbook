Explained answers

Attempt the tasks first. These are expected results for the supplied data, not a record of your own testing.

1. Exact-match lookups

Worked lookups F8:F11 should show 12, 8, 30, #N/A. The first three codes occur once in the source; X99 is absent. The index 3 returns the third column of A8:C10, which is Quantity. FALSE requests an exact match.

Changing C8 to 15 changes F8 and G18 to 15. The horizontal quantity cell B19 links to C8, so both examples use the same authoritative quantity. Restore C8 to 12. HLOOKUP's index 2 means the second row of B18:D19, not worksheet row 2.

3. Sort and filter

Ascending quantity order: Z00, A02, P01, S04, V03, F05, with quantities 0, 8, 12, 16, 30, 40. Every code must retain its original asset and medium. A quantity-only sort can silently attach values to the wrong records.

Filtering Quantity > 10 leaves P01, V03, S04 and F05 (their visible order depends on the current sort). The visible total is 98 across 4 records; the all-record SUM remains 106. Clearing the filter restores six visible records and visible total 106.

=SUM(D8:D13)
=SUBTOTAL(109,D8:D13)
=SUBTOTAL(103,A8:A13)

SUM still includes filtered-out rows. SUBTOTAL 109 sums visible quantities; 103 counts visible nonblank codes. These function numbers also exclude manually hidden rows. The initial workbook has no active filter, so the visible and all-record totals both start at 106.

4. Independent library campaign

=VLOOKUP(E8,$A$8:$C$11,3,FALSE)
=HLOOKUP(F20,$B$19:$E$20,2,FALSE)

Fill the first formula from F8 down to F13. Expected results: 18, 6, 24, 0, #N/A, #N/A. L04 has a genuine zero; L99 is absent; the final query includes a trailing space and does not match clean L02. In G20, L03 returns 24, L04 returns 0 and L99 returns #N/A.

The dollar signs preserve the source range while the test-code reference moves down. If your locale requires semicolons or translated function names, preserve the same argument meanings. Record what you changed and retest rather than copying an expected value into a formula cell.

What counts as evidence?

Keep formulas, expected and observed results, the source-change test, the sorted/filtered view and a brief explanation. A number matching the answer key is insufficient if it was typed instead of calculated. Save the full workbook rather than exporting one sheet to CSV.
