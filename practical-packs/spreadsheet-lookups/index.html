Use exact spreadsheet lookups

Start with your own copy

  1. Save the workbook under a new name and open it in a spreadsheet application that supports VLOOKUP, HLOOKUP, COUNTIFS and SUBTOTAL. Use your school's approved application.
  2. Keep the downloaded original unchanged. The amber cells identify test inputs or space for your attempt; the formula bar lets you inspect a result's formula.
  3. Begin on Worked lookups. The visible #N/A results are intentional learning cases. A missing code must not silently become quantity zero.
  4. Use the task sheet before consulting the answers. Save the editable .xlsx; a CSV cannot preserve this four-sheet workbook and its formulas.

Worked example: one source, two directions

On Worked lookups, A8:C10 holds three records. E8 is the test code. F8 contains:

=VLOOKUP(E8,$A$8:$C$10,3,FALSE)

Find the code in the first column, return the third column of the selected range, and require an exact match. The dollar signs keep that source range fixed when you fill down.

The horizontal quantity row B19:D19 links to the same source quantities. F18 is the test code and G18 contains:

=HLOOKUP(F18,$B$18:$D$19,2,FALSE)

Find the code across the first row of the selected range, then return its second row. Change C8 from 12 to 15 and predict which results change before checking. Restore 12 afterwards.

The return index counts within the selected source range. FALSE is deliberate. Exact matching does not require the keys to be sorted, but it does not prove that a key is unique.

Eight lessons inside the existing timetable

These activities occupy the existing four 55-minute lessons in each week, including explanation, practice and feedback. They are not extra lessons or compulsory homework.

  1. Week 9, lesson 1: construct a labelled resource table in your own sheet, identify keys, predict results and inspect VLOOKUP.
  2. Week 9, lesson 2: build and test a vertical exact lookup, then explain the anchored reference.
  3. Week 9, lesson 3: trace the horizontal table and compare HLOOKUP with VLOOKUP.
  4. Week 9, lesson 4: test missing codes, zero and spaces. Record the distinction between an absent record and a valid quantity.
  5. Week 10, lesson 1: sort whole records and check that their relationships survive.
  6. Week 10, lesson 2: filter a view and compare the all-record total with the visible-record total.
  7. Week 10, lesson 3: improve labels, number formats and layout, then investigate duplicate keys by swapping complete records to expose first-match behaviour.
  8. Week 10, lesson 4: complete the independent library campaign, explain corrections and save your evidence.

Self-check

  • I can explain all four arguments in each lookup.
  • I can show a source change recalculating a result.
  • I keep missing, duplicated and zero-quantity cases distinct.
  • I sort all related columns together and clear a filter without losing records.
  • I can justify my answer using the data, rather than assuming any returned number is correct.

Compatibility and sources

Formulas use English function names and commas; some application locales display different names or semicolons. Keep the intended exact-match behaviour. Blank practice cells are for your formulas. The pack was formula-tested and exported with the bundled spreadsheet engine; native Excel/LibreOffice filter interaction and classroom use still need checking in your installed version.
