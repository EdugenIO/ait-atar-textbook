Worked decisions

FocusDecision and explanation
Publication choiceAn HTML guide supports navigation and updates; a printed sheet works without a charged device but cannot play media and needs a replacement when details change. A PDF can preserve layout, yet interactive behaviour and accessibility need their own checks. Match the type to the task.
Template and framesThe supplied HTML/CSS template repeats a header, session cards and help. Cards act as content containers; in publishing software, text/image frames control placement and overflow. A template is an editable structure, not only a screenshot.
Layers and typographySeparate background decoration, text and image/overlay roles. Keep readable heading/body relationships, logical reading order and intentional spacing. A layer arrangement that looks correct may still hide text or export incorrectly.
Scheme versus profileA colour scheme selects related colours for communication. A colour profile describes colour interpretation for a device/output workflow. Selecting a blue palette does not assign, convert or verify an ICC profile.
Output-specific checksThe template’s print stylesheet removes navigation/help controls and keeps the session information in text. This is an editable HTML reference, not an ICC-verified press-ready file. Use the linked tagged/untagged artwork and output brief for actual profile/export/proof operations.

Production sequence

  1. Choose a digital publication type for a stated visitor task and justify it against another type, including a limitation.
  2. Copy and modify the supplied template in approved software. Create a second session using the same layout pattern; keep venue/time content specific.
  3. Use layers, frames/containers and deliberate typography; check overflow, reading order and required information after editing.
  4. For a screen brief, inspect the delivered layout and interactions. For print, use the linked publication pack to record actual colour-profile handling and output settings required by that brief.
  5. Reopen both outputs and inspect or proof them in the intended context. Retain source, output settings, actual observations and one revised/retested issue.

Apply independently

Complete the production sequence using your own version of the festival brief. Change the venue and one user access need, then justify and test the resulting revision. Retain your own outputs and observations; the supplied reference is a model.

Use this within the existing chapter task, not an extra assessed project or additional teaching week. Record expected and actual results separately.
