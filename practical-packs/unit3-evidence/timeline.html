Worked decisions

FocusDecision and explanation
Layer planUse the existing twelve-second source sequence as a starting point. Base picture occupies video track 1; title/venue overlays use track 2. Their timing and stacking determine the combined image.
Titles/transitions/effectsShow the title long enough to read, use a motivated cut or transition between locations and apply only an effect that serves the brief. An effect name alone does not justify its use. Check whether captions or venue text are obscured.
SoundKeep narration and supporting sound on separate tracks. A sound effect can cue a scene change; check it does not mask speech. Source peaks and final intelligibility are separate checks.
Editable versus deliveryThe linked production pack supplies a source specification, actual media exports and measured checks. A finished movie is not an editor-native multi-track project. Save your own application project and a reopened delivery copy.
InteractivityThe festival guide has links and a native expandable-help control. A video file alone does not establish interactivity; implement a meaningful action and test its result and keyboard operation.

Production sequence

  1. Open the linked editable media starter in approved software; retain the original and save an application-native working project.
  2. Create your own short sequence with at least two picture layers or multiple audio tracks, title, transition and purposeful effect; use approved/original assets.
  3. Edit a supporting sound effect and speech balance. Record intended timing and actual output observations rather than assuming the preview proves the export.
  4. Export, reopen and inspect the full delivery copy for timing, intelligibility, readable labels and caption overlap. Record settings, player and actual duration.
  5. Link or integrate the output in your own interactive festival product; test one meaningful action, revise a problem and retest.

Apply independently

Complete the production sequence using your own version of the festival brief. Change the venue and one user access need, then justify and test the resulting revision. Retain your own outputs and observations; the supplied reference is a model.

Use this within the existing chapter task, not an extra assessed project or additional teaching week. Record expected and actual results separately.
