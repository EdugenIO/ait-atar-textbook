Operate, inspect, export, proof

Return to the brief and supplied assets. These are desktop Adobe pathways based on the linked vendor documentation; record your installed version and verify labels. Use a school-approved equivalent only if it provides the same functions.

Photoshop: inspect, then prepare the screen copy

  1. Open master-srgb.png. Preserve its embedded profile when prompted. In the document status display, select Document Profile and record it; use Image Size to inspect pixels.
  2. On a duplicate, crop 36 pixels from each edge: the trim becomes 2520 × 1776. Resize that copy to 1260 × 888 pixels with resampling enabled.
  3. Use Edit → Convert to Profile if conversion to sRGB is needed. For the supplied sRGB source it is already the destination; do not assign a different profile to make it “more colourful”. Record the profile and conversion decision.
  4. Save a JPEG delivery copy using an available save/export route that embeds the colour profile. Adjust JPEG quality to meet the 500,000-byte brief, inspecting text edges after each save.
  5. Reopen the JPEG. Record actual dimensions, bytes and embedded profile. Compare it with screen-reference.jpg, allowing for different export engines. Keep the editable original.

Open untagged-comparison.png separately and inspect the absent profile. Its known teaching origin is sRGB; in a real unknown asset, ask the creator before assigning one. Assign Profile changes interpretation; Convert to Profile transforms values using a known source.

InDesign: prepare the print layout and export checks

  1. Create a landscape document with a 210 × 148 mm page, 3 mm bleed on every side and an 8 mm safe text margin for this exercise.
  2. Place the tagged raster master at 216 × 154 mm with its top-left corner at −3, −3 mm relative to the page. It already includes the bleed, so do not stretch or crop it a second time. At that size the raster is 304.8 effective PPI.
  3. Check links and preflight findings, including missing fonts and resolution. If using the editable SVG, inspect font substitutions and import handling; vector text behaviour depends on the application and export.
  4. Get the printer’s accepted PDF standard, profile, conversion/retention policy and mark requirements. Do not adopt a generic CMYK profile as a substitute for this information.
  5. Choose File → Export and Adobe PDF (Print). In Marks and Bleeds use the document bleed. Add marks only if requested. In Output set the agreed conversion and destination/profile policy; use the printer’s required preset or standard rather than a universal recipe.
  6. Open the exported PDF in a suitable inspector. Verify the trim/bleed boxes, image quality, fonts and colour/output-intent information required by the printer. A preset name alone is not proof that every requirement was met.

No destination printer profile is supplied in this pack, so colour-managed print approval is pending. Save a settings record and questions for the printer instead of labelling an unverified PDF “print ready”.

Soft proof before physical approval

In Photoshop use View → Proof Setup → Custom and choose the agreed output profile and options. Toggle View → Proof Colors to compare the simulation; record the profile, rendering intent and applicable paper/black simulation choices. This preview changes the view, not the delivery file. Display condition and profile suitability limit what it can tell you. Obtain and inspect an appropriate physical proof for the real print job.

Independent transfer

The client changes the screen requirement to 840 pixels wide, with the same aspect ratio, and asks for a second print size. Calculate the screen height, make a new export, and recompute effective PPI at the new placed width. Recheck all delivery conditions rather than reusing a filename with unchanged settings.

Compare reasoning

The screen height is 592 pixels because 1260:888 reduces to 840:592. Byte size must be measured after saving. Enlarging the print placement reduces effective PPI for the same raster pixel count.
