# Interactive pilots: edition 0.24

Audience: 16–17-year-old AIT ATAR students, with optional teacher reference notes. No accounts, grading, tracking or submissions.

## Included in this release

- Typography: five concrete topic examples, a poster comparison, native controls for alignment/size/spacing, reset, explanation scaffold, paper alternative and teaching notes.
- Data recovery: choose a traditional full, differential or incremental schedule; change the failure time; make the Wednesday backup file unavailable. The timeline identifies exact restore dependencies, latest usable backup and potential missing-work window. Model assumptions are explicit. Restore duration is not estimated.
- Digital participation: compare three fictional workshop-booking approaches through participant and volunteer perspectives. Explain benefits, barriers, mitigations and questions to investigate. There are no scores or prescribed universal winner. Includes a paper activity and teaching notes.
- Every chapter resource page now has existing syllabus context and a link to complete source/teaching notes.

## Verification

Release checks cover content preservation, topic navigation, glossary destinations, print-click behaviour, student/answer separation, practical pack links and local response lab rules. Behaviour tests cover typography state/reset and all 18 backup-method/failure/missing-copy combinations. Scenario tests cover each perspective choice and reset.

Browser checks verified the missing incremental chain and differential comparison, and switching the participation approach. Native controls support keyboard use; responsive checks inspect the new timeline and perspective layouts at 390 px. Actual classroom review remains pending. These are instructional models, not simulations of a named production backup tool or claims about a real community.

## Next step after release

Review the three pilots with a teacher and a small student group. Record which explanations are unclear, whether each interaction helps learners explain the concept, and where examples need more depth. Use that feedback before rolling the approach across all chapters. The comprehensive legacy chapter and unit worksheets remain available; new pilots have their own printable page content.
