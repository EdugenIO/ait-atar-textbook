# Repetition and reading-structure audit

Reviewed the shared renderer and the section, worked-example, question and resource inventories for all 24 chapters. This is a structural/content-role audit; it is not independent subject review or a claim that every paraphrased question is redundant.

## Decisions applied across all chapters

| Existing block | Decision and distinct purpose |
|---|---|
| Objectives, introduction | Keep on chapter overview to establish scope once. |
| Retrieval | Keep as optional prerequisite recall on overview; distinguish earlier-learning retrieval from restating a new explanation. |
| Explanatory sections | Give each named concept its own address and previous/next navigation. Preserve explanation text and its associated diagram. |
| Section diagrams | Keep beside their relevant concept, rather than adding all visuals to one reading page. |
| Chapter visual and generated process image | Move to visual walkthrough; show the authored visual first and make the alternative process view optional. These are alternative explanations, not consecutive required steps. |
| Worked example and guided question | Keep together: modelling followed by supported application. |
| Independent task and recap | Keep on application page; success criteria available on request. |
| Three practice questions, misconception, transfer task | Move to optional practice. These provide different prompts, but need not interrupt the core reading path. |
| Spot-the-mistake and completion questions | Nest under additional practice; do not automatically repeat these activity types after every worked example. |
| Quick check and exit question | Keep exit reflection in optional practice; remove multiple-choice quick check from the new reading route to avoid another compulsory-looking review. Retain in complete legacy chapter and worksheets where already available. |
| Repeated general instructions | Remove repeated instructions about writing first, correcting reasoning, evidence and extra homework from the focused topic routes. Use labels at the point of action. |
| Practical links and downloads | Collect into one resource page per chapter. Deduplicate exact destinations, retaining genuinely different resources. |
| Scheduled lessons and teaching references | Move scheduled links to resources. Preserve full syllabus/source notes in the complete chapter. |
| Complete chapter | Retain as an explicitly labelled read/print alternative and for existing deep links, rather than the default screen. |

## Limits and follow-up

The new topic pages reuse existing explanations; they do not represent newly authored depth. No syllabus concepts or question source data were deleted. The next editorial pass should add a concrete example where an individual topic is too brief, consolidate genuinely equivalent questions after teacher review, and give selected pages a topic-specific experience using the engagement plan. Do not inflate every short page with a repeated activity template. Shared worksheets remain comprehensive and retain their existing print contract.
