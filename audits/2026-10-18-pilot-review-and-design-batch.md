# Pilot review and next design batch — edition 0.25

## Scope and evidence

This is an author/usability review, not student or teacher classroom feedback. Review of the three edition-0.24 pilots checked the reading tasks, stated assumptions, teacher/student separation, control behaviour, recovery calculations and discovery routes. Classroom review remains pending.

The pilots use different learning actions: adjust and compare a layout; trace recovery dependencies; consider stakeholders and trade-offs. No scores, accounts or submissions are used. Technical vocabulary is retained and explained with a concrete scenario. Teacher notes are optional and are omitted from student print mode.

## Finding and fix

Search indexed topic explanations and chapter titles, but excluded special experience titles. Added direct search matches for authored experience pages. Existing topic and chapter matches remain available. This supports finding the pilots without knowing which chapter contains them.

## Next design batch

- Understanding a design brief: investigate five clues in one fictional request. Separate client, audience, purpose, constraints and unknown information. Turn a missing detail into a useful question.
- Elements: adjust tone difference, accent colour and venue size while preserving the words. A written description communicates the changes without relying on colour alone. The deliberately subtle-text example is instructional, not a certified accessible design; explanatory text and controls remain separate and readable.
- Principles: compare two layouts with identical event wording. Explain hierarchy, proximity and contrast, then change the purpose and reconsider the hierarchy. This is an authored comparison, not measured proof that one layout is universally superior.

Each experience is a named page in its chapter. All have teacher notes, context-specific prompts and a non-interactive/paper route. No repeated generic quiz block was added.
